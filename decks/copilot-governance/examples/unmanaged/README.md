# Unmanaged posture

This posture intentionally has no `managed-settings.json`.

Users and workspaces choose their own models, permissions, plugins, marketplaces,
MCP servers, telemetry, remote-control behavior, and sandbox settings. Use this
only where central policy is not required and the organization accepts the
resulting variation and limited assurance.

The string value `"unmanaged"` is valid only for documented team-overridable
settings. It is not a universal value that disables all enterprise governance.
