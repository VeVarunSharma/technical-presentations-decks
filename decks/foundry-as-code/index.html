Why change the operating model?

Portal state is useful. It is not a delivery system.

The problem is not clicking. The problem is configuration that cannot be reviewed, reproduced, tested, or promoted consistently.

02

Drift

Dev, staging, and production silently stop matching.

02

Hidden decisions

03

Behavior without a contract

Agent changes ship without a versioned use-case dataset or acceptance criteria.

04

Weak release evidence

A successful deployment says the agent started—not that it still works.

Decision: manage agent topology, code, evaluation assets, and release policy together in Git.
