# Microsoft brand profile placeholder

No Microsoft brand tokens or assets are committed here. Do not infer colors,
typography, logos, spacing, or templates from memory or from screenshots.

The provided internal SharePoint presentation resource is **reference-only**.
It must not be downloaded, committed, redistributed, or converted into local
tokens. Until an authorized owner supplies approved, redistributable Microsoft
design-system materials, use the `neutral` profile and label Microsoft marks
only with separately approved assets.

This directory intentionally contains no `brand.json` or `tokens.css`: creating
them without an authoritative approved source would falsely imply a supported
Microsoft profile.
